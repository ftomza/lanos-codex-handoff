# Android M5.2 Implementation Plan

**Goal** Receive and display the Vgate adapter's ATI reply on Android.
**Spec** [Android M5.2 design](../specs/2026-11-23-android-m52-design.md).

1. Add tests in `AdapterProbeTest.kt` with a fake GATT link and scheduler.
   Cover operation order, fragments and echo, fixed write, stage timeout,
   bounded retry, stale callbacks, cancellation, rejected frames and buffer limits.
2. Implement `AdapterProbe`, then bind it to Android in `AndroidGattLink.kt`.
   Keep callbacks serialized on the main thread and fence each attempt.
3. Add `ProbeActivity`, permissions and the Android dashboard entry. Verify
   the activity launches, opens only after a tap, and leaves the simulator usable.
4. Run JVM and web tests, lint and debug APK build. Update the Android README,
   PLAN and STATUS with results, installation and separate physical acceptance.
