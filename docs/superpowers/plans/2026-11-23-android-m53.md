# Android M5.3 Implementation Plan

**Goal** Display actual RPM, coolant and ATRV in LIVE on Android.
**Spec** [Android M5.3 design](../specs/2026-11-23-android-m53-design.md).

1. Run failing Kotlin tests for the physical Go capture replay, exact decoding,
   capability and independent freshness, and serialized fake GATT exchanges.
2. Generalize the bounded frame and typed GATT write. Implement live polling,
   per-command deadlines, stale values and synchronization after a lost prompt.
3. Add an explicit live/simulator switch with BLE permission prompts. Keep
   navigation restricted to the local dashboard and approved user gestures.
   Verify LIVE handoff and no fallback/stale display with the real view model.
4. Run Android, Node and Go checks, check the APK on an emulator, and install it
   on the connected tablet. Record actual verification and the parked car
   checklist, then stop before M5.4.
