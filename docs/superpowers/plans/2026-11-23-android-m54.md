# Android M5.4 Implementation Plan

**Goal** Keep Android LIVE usable across ignition changes and transient BLE errors.
**Spec** [M5.4 design](../specs/2026-11-23-android-m54-design.md).

1. Test the new supported inputs and the scheduler against a deterministic clock.
2. Test standby and recovery against fake GATT, then add the LIVE polling state
   machine and integrate it with the existing serialized connection.
3. Check WebView status for waiting, stale and independent voltage. Retain the
   previous native permission, simulator and ATI paths.
4. Run the Android and Go/web checks, build the debug APK, verify the foreground
   screen on the emulator or tablet, and record the parked-car test checklist.
