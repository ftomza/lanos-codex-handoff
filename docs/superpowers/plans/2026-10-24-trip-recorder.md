# Trip Recorder Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task in the existing feature branch. No delegation is authorized.

**Goal:** Record capability-gated trip telemetry incrementally for later fuel estimation research.

**Architecture:** Add --record to obdprobe. Reuse probe initialization, discovery,
command serialization and recovery with a streaming command observer; add a
bounded JSONL writer independent of the transport. Keep finite probe reports
compatible and the dashboard simulator-only.

**Tech Stack:** Go 1.27, standard library, existing native BLE helper and serial transport.

### Task 1: Private streaming event writer

Files: create internal/record/event.go, writer.go, writer_test.go; create
internal/privacy/json.go and json_test.go; reuse redaction in cmd/obdprobe/output.go.

- [x] Write tests for independent JSON lines, sequence/version, exact nanosecond
  preservation, VIN/error redaction, exclusive 0600 files, write/sync failures,
  size-limit final-event reserve and partial writes.
  Test contract: `w, err := Open(path, true); err = w.Write(Event{Type:
  "command", Timestamp: time.Now(), Data: map[string]any{"raw": vin}})`;
  read and decode every line, verify version=1, sequence increasing and no VIN.
