# Наблюдения и возможности OBD

Источник: [GitHub Issue #1](https://github.com/ftomza/lanos-codex-handoff/issues/1),
сессия пользователя от 2026-10-24. Это физическое наблюдение из задачи, а не новый
аппаратный тест Go-программы. Точная модель ЭБУ, версия прошивки адаптера и
совместимость других машин/адаптеров не установлены.

В [уточнении владельца](https://github.com/ftomza/lanos-codex-handoff/issues/1#issuecomment-6383158184)
модель исправлена на **Vgate iCar Pro BLE 4.0 Dual**. Ранее указанная Bluetooth 3.0
была ошибкой в описании модели. Подтверждён Classic SPP на MacBook M3 через
`/dev/cu.Android-Vlink`. Позднее Go probe физически открыл порт, но не получил
ответа на ATZ; успешный обмен через Go пока не подтверждён (см. STATUS.md).
Bluetooth отключался даже при открытом порте без команд; новых ECU-ответов нет.
BLE GATT, UUID сервисов/характеристик и одновременная работа двух
транспортов пока не проверены; стандартный BLE UART не предполагается.

## Что фактически получено

| Запрос | Ответ без завершающих CR/prompt | Интерпретация |
| --- | --- | --- |
| `ATZ`, `ATI` | `ELM327 v2.3` | Строка самоидентификации; не доказательство происхождения прошивки. |
| `ATE0`, `ATL0`, `ATS0`, `ATH0`, `ATSP0` | `OK` | Адаптер принял настройки echo/форматирования/автовыбора протокола. |
| `0100` | `SEARCHING...`, `4100BE3EB811` | Достоверный bitmap диапазона 01–20. |
| `ATDPN` | `A5` | Автовыбор, ISO 14230-4 KWP2000 fast init. Не идентифицирует модель ЭБУ. |
| `010C` | `410C0000` | 0 rpm; ноль является полученным значением. |
| `0105` | `410576` | `0x76 - 40 = 78 °C`. |
| `010D` | `410D00` | 0 км/ч. |
| `03` | `43000000000000` | В этом ответе нет сохранённых DTC. Не исключает pending/permanent codes. |

Порт в задаче: `/dev/cu.Android-Vlink`; скорость baud не указана. Переключение
зажигания иногда разрывало Bluetooth-соединение. Check Engine на момент записи
задачи не горел. Приведённые ответы не содержат временных меток отдельных команд,
поэтому фикстура не придумывает их.

Точные байты с CR и prompt хранятся в
`internal/elm327/testdata/vgate-2026-10-24.json`. Дополнительные ответы `0120`,
`0101`, `ATRV`, тестовые DTC и ненулевые RPM в тестах — **синтетические** проверки,
а не результаты подключения к этой машине.

Фикстура и новые отчёты отдельно хранят owner-reported модель и источник
уточнения. `adapter` продолжает означать реальную строку `ATI`; она сама по себе
не определяет продуктовую модель. Текущий `transport` — `serial_spp`.

## Bitmap BE3EB811: объявленная поддержка

Установлены PID: `01 03 04 05 06 07 0B 0C 0D 0E 0F 11 13 14 15 1C 20`.

| PID | Сигнал | Факт из физической сессии |
| --- | --- | --- |
| 01 | MIL / readiness / число сохранённых DTC | Объявлен; значение ещё не считано. |
| 03 | Fuel system status (Mode 01, не DTC-команда Mode 03) | Объявлен; не считан. |
| 04 | Расчётная нагрузка | Объявлен; не считана. |
| 05 | Температура ОЖ | Считана: 78 °C. |
| 06 / 07 | Кратко-/долгосрочная коррекция, банк 1 | Объявлены; не считаны. |
| 0B | MAP | Объявлен; не считан. |
| 0C | Обороты | Считаны: 0 rpm. |
| 0D | Скорость | Считана: 0 км/ч. |
| 0E | Угол опережения | Объявлен; не считан. |
| 0F | Температура впускного воздуха | Объявлена; не считана. |
| 11 | Дроссель | Объявлен; не считан. |
| 13 | Наличие кислородных датчиков | Объявлено; bitmap датчиков ещё не считан. |
| 14 / 15 | Кислородные датчики 1 / 2 | Объявлены; данные ещё не считаны. |
| 1C | Соответствие стандартам OBD | Объявлено; не считано. |
| 20 | Bitmap следующего диапазона | Запрос `0120` разрешён; его реального ответа ещё нет. |

В диапазоне 01–20 **не объявлены** PID
`02 08 09 0A 10 12 16 17 18 19 1A 1B 1D 1E 1F`.
В частности, MAF (`10`) этой сессией не поддержан. Эти PID probe не запрашивает.

Уровень топлива `2F`, напряжение ЭБУ `42`, расход топлива `5E` и прочие PID выше
20 пока **не проверены**, а не признаны неподдерживаемыми. Нужны ответы цепочки
bitmap: `0120`, затем `0140` только при объявленном PID 40 и т. д.
Наличие MAP/IAT/RPM в bitmap ещё не доказывает пригодность или точность топливной
оценки M6. Никаких выводов о поворотниках, освещении или прочих кузовных сигналах.

`ATRV` — напряжение, измеренное адаптером, не значение аккумулятора от ЭБУ.
Реального ответа `ATRV` в Issue #1 нет; он остаётся непроверенным.

## Состояния нового отчёта

`support` отделён от результата отдельного чтения (`status`). В новом отчёте
`captured_at` — время получения/декодирования полного ответа на Mac, не метка
времени от ЭБУ. Исторические наблюдения из Issue #1 датированы только днём.

- `supported`: PID указан полученным bitmap; это ещё не успешное измерение.
- `unsupported`: бит отсутствует в успешно прочитанном диапазоне.
- `not_yet_tested`: диапазон/измерение ещё не исследован либо bitmap недоступен.
- `temporarily_unavailable`: объявленный PID ответил `NO DATA`, `STOPPED`,
  отрицательным ответом или иной ошибкой; поддержка не сбрасывается.
- `available`: есть валидное декодированное чтение; `raw_only`: есть корректный
  положительный payload, но декодер для него не реализован.
- `invalid_response`: некорректный payload; числовое значение отсутствует.
- `stale`: чтение было получено в неудавшейся сессии; экспортируется без числового
  значения, с сохранением raw/timestamp для аудита.

Каждый новый attempt строит матрицу заново. Предыдущие команды остаются в журнале,
но показания не переносятся в новую сессию. `NO DATA` никогда не становится нулём
или доказательством неподдержки. Пустой список DTC считается подтверждённым только
при `stored_dtcs.status=available` и валидном ответе 43.

## Следующие проверки

1. Устранить текущий обрыв adapter/SPP, получить AT-ответ; затем выполнить Go
   probe на припаркованном автомобиле по NEXT_CONNECTION.md.
2. Сохранить реальные `0120`, `0101`, `ATRV` и объявленные MAP/IAT/trim/O2 PID.
3. Отдельно проверить остановку/повторное подключение при смене зажигания.
4. После подтверждения формата — отдельный M4: live Source для приборки с
   per-PID freshness/capability, polling и reconnect, без подстановки симулятора.
5. Позже решить, нужны ли отдельные read-only режимы pending/permanent DTC и
   идентификации. Сейчас Mode 07/0A/09 и VIN не запрашиваются.
